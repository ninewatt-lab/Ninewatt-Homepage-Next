# 랜딩 페이지 스크린샷

홈 페이지 (`/`) 에서 참조하는 이미지를 여기에 넣어주세요.

## 필요한 파일

| 파일명 | 캡처할 페이지 | 권장 해상도 | 비고 |
|---|---|---|---|
| `power-grid.png` | `/power-grid` | 1920×1080 | 전력망 지도. 발전소 클릭해 팝업이 뜬 상태가 보기 좋음 |
| `map-analysis.png` | `/map` | 1920×1080 | 지도 기반 필지 분석. 필지가 선택된 상태 |
| `shadow-analysis.png` | `/solar-analysis` | 1920×1080 | 3D 음영 분석. 태양 위치와 그림자가 뚜렷한 시간대 |
| `business-analysis.png` | `/analysis` | 1920×1080 | 사업성 검토. 분석 결과 탭이 열린 상태 |
| `dashboard.png` | `/dashboard` | 1920×1080 | 대시보드. 최근 프로젝트와 Quick Actions 포함 |
| `report.png` | `/report` | 1920×1080 | 리포트 화면. 주소 검색 + verdict 결과 |

## 캡처 팁

1. 브라우저 창 최대화 → DevTools 닫은 상태
2. 다크 테마 권장 (지도 페이지는 다크가 훨씬 깔끔함)
3. 현실적 데이터가 보이게 (빈 상태 말고 실제 사용 시나리오)
4. PNG 로 저장, 가능하면 100~400KB 이내로 최적화 (TinyPNG 등)
5. 파일명은 위 표 정확히 일치

## Optional: 히어로 이미지

`hero.png` 를 추가하면 헤더 아래 큰 이미지로 사용됨. 없으면 `power-grid.png` 를 폴백으로 사용.
